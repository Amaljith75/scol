# Inbox: drop raw material here

Got a syllabus PDF, a photo of notes, or a rough text file and no time to format it?
Put it in this folder. Nothing in `_inbox` is shown in the app.

Later, turn each piece into a `notes.md` or a lesson file inside the right chapter folder
(see `content/README.md`). You can also paste the raw notes to an AI assistant and ask it to
"convert this into Scol notes.md format" and then review the result before saving it.

Please do not upload scanned pages of SCERT or NCERT textbooks here. This repository is public,
and the textbooks are copyrighted. Write the ideas in your own words instead.
